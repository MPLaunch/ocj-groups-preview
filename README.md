# OCJ Groups - website concept (MP Launch)

Seven-page design concept for ocjgroups.com.au. Unlisted and noindexed.
`node build.mjs` regenerates every page from one file. Every fact about the business traces to their own
live site (29 Sep 2026), their Instagram, or Peter's call with Joe on 29 Sep 2026 - see the sourcing notes at
the top of `build.mjs`.
